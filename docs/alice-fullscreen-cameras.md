# Управление полноэкранными камерами через Алису

Селектор камеры Viewpie в Home Assistant — это сущность домена `select`.
Для голосового управления через Yandex Smart Home удобнее создать отдельный
скрипт на каждую камеру и открыть эти скрипты для Яндекса как переключатели.

Пример для камеры «Двор» (замените entity_id и option на значения из своей HA):

```yaml
script:
  viewpie_camera_yard_fullscreen:
    alias: "Камера двор на весь экран"
    icon: mdi:cctv
    sequence:
      - service: select.select_option
        target:
          entity_id: select.viewpie_fullscreen_camera
        data:
          option: "Двор"
```

Скопируйте блок с другим уникальным именем скрипта и названием камеры для
каждой камеры, которой нужно управлять голосом. Значение `option` должно
точно совпадать с названием камеры в списке вариантов сущности
`select.*fullscreen_camera`.

Для голосового выбора панели создайте аналогичный скрипт, но используйте
селектор панели. Например, для панели с ID `panel1`:

```yaml
script:
  viewpie_panel_cameras_1_4:
    alias: "Открыть панель камеры с первой по четвёртую"
    icon: mdi:view-dashboard
    sequence:
      - service: select.select_option
        target:
          entity_id: select.viewpie_panel
        data:
          option: "panel1"
```

Замените `panel1` на ID нужной панели из списка вариантов
`select.*panel`. Название скрипта задайте так, как удобно произносить Алисе.

**Отдельно включать экран в скрипте не требуется.** Интеграция проверяет
состояние Viewpie перед переключением: если видеостена была на паузе
(экран выключен), сначала отправляет команду включения экрана и дожидается
её выполнения, а затем открывает выбранную камеру. Это работает как для
скриптов Алисы, так и при выборе камеры/панели непосредственно в Home Assistant.

Чтобы вернуть обычную раскладку, можно создать отдельный скрипт:

```yaml
script:
  viewpie_return_to_panels:
    alias: "Вернуть панели камер"
    icon: mdi:view-dashboard
    sequence:
      - service: select.select_option
        target:
          entity_id: select.viewpie_fullscreen_camera
        data:
          option: "Grid"
```

После перезагрузки/перечитывания скриптов откройте настройки Yandex Smart Home,
разрешите передачу созданных скриптов и обновите список устройств в приложении
«Дом с Алисой». Названия скриптов задавайте разговорными: например,
«Камера двор на весь экран». Тогда команда Алисе будет звучать как
«Алиса, включи камеру двор на весь экран».

Выбор камеры переключает видеостену на полноэкранный поток; выбор `Grid`
возвращает активную панель. Если в настройках Viewpie задан тайм-аут
полноэкранного режима, камера автоматически сменится обратно по этому таймеру.
